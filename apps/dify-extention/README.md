# Dify Agent Sidepanel Extension

사이드패널에 Dify Agent를 내장하고 웹페이지 내의 데이터(DOM)를 간편하게 추출, 정제하여 클립보드로 전송하는 크롬 확장 프로그램입니다. 사내 내부 도구용으로 별도의 스토어 등록 없이 안전하게 배포됩니다.

## 📥 설치 및 사용 방법 (사용자용)

1. 저장소 우측의 **Releases** 탭으로 이동합니다.
   * **테스트 진행 시:** `latest-test` 프리 릴리즈 탭에서 어셋 다운로드
   * **정식 버전 사용 시:** 최신 정식 버전 번호(`vX.Y.Z`) 탭에서 어셋 다운로드
2. `dify-agent-sidepanel-[버전].zip` 파일을 다운로드한 후, 원하는 경로에 압축을 해제합니다.
3. 크롬 브라우저를 열고 주소창에 `chrome://extensions/`를 입력합니다.
4. 우측 상단의 **[개발자 모드]** 토글을 켭니다.
5. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다.]** 버튼을 클릭합니다.
6. 압축을 해제했던 폴더(내부에 `manifest.json`이 위치한 폴더)를 선택하면 설치가 완료됩니다.

## 💡 주요 기능
* **사이드바 상시 대기:** 툴바에서 익스텐션 아이콘을 클릭하여 Sidepanel을 엽니다.
* **스마트 스캐닝:** Sidepanel이 활성화된 상태에서 웹페이지 내 텍스트에 마우스를 올리면 테두리가 블루 색상으로 강조됩니다.
* **컨텐츠 추출 및 정제:** 강조된 요소를 클릭하면 연속 공백 제거 등의 정제 가공을 거친 뒤 클립보드에 자동으로 복사됩니다.
